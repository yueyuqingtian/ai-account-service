# 数据库设计

## 1. 设计原则

- 核心业务表使用 InnoDB
- 主键统一使用 `bigint` 或雪花 ID
- 金额字段使用 `decimal(10,2)`
- 状态字段使用短字符串或 tinyint 枚举均可，本方案文档用字符串描述
- 时间字段统一包含 `created_at`、`updated_at`
- 敏感数据字段采用密文存储

## 4. 关系说明

- 一个用户可以有多个订单
- 一个订单对应一个支付单，也可扩展为多次支付尝试
- 一个已支付订单通常绑定一个 CDKey
- 一个 CDKey 成功兑换后关联一条库存资源
- 一个库存资源只能被一个兑换记录成功关联

## 5. 数据安全要求

- 库存密码字段只存密文
- 回调原文按需脱敏或压缩
- 管理员日志不可物理删除，建议逻辑归档
