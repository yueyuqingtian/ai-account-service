# v5.0test 功能细节迭代说明

## 1. 发布目标

v5.0test 继续补齐账号购买平台的基础运营能力，重点增强注册验证、商品图片、支付商户配置和收款码配置。

## 2. 本次新增能力

### 注册登录

- 注册前支持向用户邮箱发送验证码
- 注册接口校验邮箱验证码
- 验证码 10 分钟有效
- 验证码使用后失效
- 后台未配置发信邮箱时，测试环境返回开发验证码，便于本地验收

### 邮箱配置

- 后台邮箱配置增加 SMTP Host
- Gmail 邮箱和应用密钥同时用于：
  - IMAP 查询 OpenAI 登录验证码
  - SMTP 发送注册验证码

### 商品管理

- 后台商品管理支持上传商品封面图
- 上传成功后自动回填商品封面 URL
- 上传文件通过 `/uploads/**` 静态访问

### 支付配置

- 后台支持保存支付宝商户信息
- 后台支持保存微信商户信息
- 支持上传支付宝收款二维码
- 支持上传微信收款二维码
- 支付创建时优先使用后台配置的收款二维码 URL
- 敏感密钥加密存储

## 3. 新增接口

用户端：

- `POST /api/auth/send-register-code`
- `POST /api/auth/register`

后台：

- `POST /admin/uploads/image`
- `GET /admin/payment-config`
- `POST /admin/payment-config`
- `GET /admin/email-config`
- `POST /admin/email-config`

## 4. 验收路径

1. 进入后台邮箱配置，配置 Gmail 和应用密钥
2. 进入用户端注册页，输入邮箱并发送验证码
3. 使用收到的验证码完成注册
4. 进入后台商品管理，上传商品封面并保存商品
5. 进入后台支付配置，填写支付宝/微信商户信息
6. 上传支付宝/微信收款二维码
7. 用户端购买商品，查看支付面板是否使用对应渠道信息

## 5. 当前边界

- v5.0test 仍保留 Mock 支付成功用于本地完整闭环
- 支付宝/微信真实 SDK 下单与验签仍属于后续正式版本
- 注册验证码 SMTP 发送依赖后台邮箱配置
- 图片上传保存在本地 `uploads` 目录，生产环境建议迁移到对象存储
