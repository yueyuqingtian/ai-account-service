# 后端系统设计

## 1. 总体架构

后端采用单体分层架构，按领域拆包，保证初期开发效率与后期演进空间。

推荐包结构：

```text
com.company.gptplus
├─ common
├─ auth
├─ user
├─ product
├─ order
├─ payment
├─ cdkey
├─ inventory
├─ redeem
├─ risk
├─ admin
└─ audit
```

## 2. 分层规范

### Controller 层

职责：

- 参数接收
- 鉴权
- 参数校验
- 返回统一响应结构

### Application 层

职责：

- 编排跨领域流程
- 执行业务用例
- 处理事务边界

### Domain 层

职责：

- 表达领域对象
- 承载核心规则
- 约束状态流转

### Infrastructure 层

职责：

- DAO
- Redis
- MQ 预留
- 第三方支付接入
- 对象存储

## 3. 关键模块设计

## 3.1 认证模块

能力：

- 用户注册
- 用户登录
- JWT 签发与刷新
- 管理员角色鉴权

建议：

- 用户端与管理后台分开角色体系
- 管理员接口统一使用权限注解控制

## 3.2 商品模块

能力：

- 商品分页查询
- 商品详情查询
- 商品后台增删改查
- 上下架与排序

关键规则：

- 已下架商品不可创建新订单
- 售价修改不影响历史订单快照

## 3.3 订单模块

能力：

- 创建订单
- 查询订单
- 关闭超时订单
- 更新交付状态

关键规则：

- 下单时写入价格快照
- 创建订单时校验商品状态
- 未支付订单定时关闭

## 3.4 支付模块

能力：

- 创建支付单
- 支付渠道适配
- 回调验签
- 幂等更新

关键规则：

- 先记录原始回调，再执行业务逻辑
- 成功回调只允许将订单从未支付改为已支付一次

## 3.5 CDKey 模块

能力：

- 随机生成卡密
- 支付成功后绑定卡密
- 查询用户卡密
- 卡密作废与锁定

关键规则：

- 卡密编码需全局唯一
- 卡密只在订单支付成功后发放

## 3.6 库存模块

能力：

- 批量导入账号库存
- 状态切换
- 可用库存查询
- 锁定与分配

关键规则：

- 密码字段加密存储
- 禁止明文全量导出

## 3.7 兑换模块

能力：

- 兑换卡密
- 获取交付结果
- 记录兑换日志
- 风控前置校验

标准流程：

1. 校验登录态
2. 校验 CDKey 是否存在
3. 校验 CDKey 状态是否可用
4. 获取 Redis 锁
5. 开启事务
6. 锁定 CDKey
7. 查询并锁定一条可用库存
8. 写入兑换记录
9. 更新 CDKey 为已使用
10. 更新库存为已分配
11. 提交事务
12. 返回交付信息

## 3.8 风控模块

能力：

- 下单限频
- 兑换限频
- 黑名单 IP 拦截
- 异常重复支付识别

建议策略：

- 同一 IP 5 分钟内兑换失败超过阈值则临时封禁
- 同一账号每日兑换次数限制
- 新注册用户增加校验强度

## 4. 事务与锁设计

## 4.1 事务边界

- 订单创建单独事务
- 支付回调单独事务
- 兑换流程单独事务
- 后台批量导入按批次切分事务

## 4.2 锁策略

- Redis 分布式锁：用于兑换入口幂等保护
- 数据库行锁：用于锁定库存记录
- 唯一索引：用于约束卡密、订单号、支付单号

## 5. 统一响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

错误结构：

```json
{
  "code": 40001,
  "message": "CDKey 已使用",
  "data": null
}
```

## 6. 日志与审计

必须记录：

- 订单创建日志
- 支付回调日志
- 兑换成功与失败日志
- 管理员敏感操作日志
- 库存导入日志

日志字段建议包含：

- traceId
- userId
- orderNo
- paymentNo
- cdkCode
- clientIp
- operatorId

## 7. 异常设计

建议错误码分段：

- `10000-19999`：认证与用户错误
- `20000-29999`：商品与订单错误
- `30000-39999`：支付错误
- `40000-49999`：CDKey 与兑换错误
- `50000-59999`：库存与后台错误

## 8. 可观测性

- 健康检查接口
- Prometheus 指标采集预留
- 慢 SQL 日志
- 支付回调与兑换流程耗时统计
