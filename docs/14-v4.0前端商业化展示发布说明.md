# v4.0 前端商业化展示发布说明

## 1. 发布目标

v4.0 聚焦前端展示质量，将项目从“功能可用”升级为更适合商用账号购买平台的界面体验。

本版本不改变核心后端业务链路，重点优化：

- 用户端视觉质感
- 商业化购买引导
- 商品详情与支付信息层级
- CDKey 兑换与验证码查询体验
- 管理后台运营工作台观感
- 商品管理表单和列表展示

## 2. 用户端优化

- 重做全局视觉系统
- 新增商业化首页首屏
- 首页增加平台保障、购买流程、精选商品展示
- 商品卡片改为更有销售感的卡片样式
- 商品详情页升级为图片展示区 + 购买面板
- 支付信息改为独立待支付面板
- 登录页升级为品牌化登录/注册页
- CDKey 兑换页升级为双栏信息布局
- 验证码查询页升级为更清晰的查询服务页
- 我的权益页增加页头、标签态和刷新入口

## 3. 管理后台优化

- 重做后台全局视觉系统
- 侧边栏升级为运营台风格
- 仪表盘增加数据说明和运营建议
- 商品管理页升级表单布局
- 商品列表增加封面、状态标签和更清晰的商品信息展示
- 表格、按钮、输入框、卡片统一样式

## 4. 设计原则

- 商用平台风格，不做营销空壳
- 第一屏直接表达账号购买、自动发卡、验证码查询能力
- 页面信息密度适中，避免过度装饰
- 主要操作按钮明确，状态反馈清晰
- 用户端偏购买转化，管理端偏运营效率

## 5. 验证项

需要验证：

- 用户端首页可正常打开
- 商品详情页可正常创建订单
- 支付面板可正常展示
- 兑换页可正常兑换账号
- 验证码页可正常提交查询
- 后台仪表盘可正常加载
- 后台商品管理可新增、编辑、上下架
- 前端生产构建通过

## 6. 当前边界

- v4.0 主要是界面优化版本
- 未引入大型 UI 组件库
- 未引入图标库，保持当前项目依赖轻量
- 后续可继续补充移动端细节和端到端截图验收
