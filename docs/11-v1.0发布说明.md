# v1.0 发布说明

## 发布版本

- 版本号：`v1.0.0`
- 发布日期：2026-05-01
- 发布类型：MVP 首版

## 发布目标

本版本用于完成虚拟权益/CDKey 售卖与兑换系统的第一版闭环交付，使项目从文档方案进入可运行、可联调、可演示状态。

## 支付能力说明

v1.0 已完成支付渠道建模和统一入口，支持：

- `ALIPAY`
- `WECHAT`
- `MOCK`

当前版本为了保证本地开发与演示闭环，支付宝和微信支付先进入渠道适配入口，支付成功仍通过 Mock 接口触发。

后续接入真实支付时，需要补齐：

- 支付宝签名、下单、回调验签
- 微信支付 JSAPI/NATIVE 下单、回调验签
- 商户证书与密钥管理
- 生产回调域名
- 对账与退款能力

## 历史演示账号

早期版本曾内置演示管理员账号和演示库存；当前版本已移除默认账号和测试数据，请在目标环境中手动创建正式管理员、商品和库存。

演示商品：

- 当前版本不再预置演示商品或演示库存

## 已知边界

- v1.0 使用 H2 作为本地开发数据库，MySQL 脚本已保留
- 真实支付宝、微信支付尚未填入商户密钥和验签实现
- 当前 Token 方案适合 MVP 演示，生产应替换为完整 JWT 密钥轮换与刷新机制
- 库存密码字段在开发模式中未加密，生产应接入 KMS 或应用层加密
- 后台权限目前只区分管理员身份，细粒度角色权限后续增强
