# 前端管理后台设计

## 1. 目标

管理后台服务于运营、客服、财务、管理员，核心是提高商品运营、订单追踪、库存控制、兑换排障与审计效率。

## 2. 路由结构

- `/login`
- `/dashboard`
- `/products`
- `/orders`
- `/payments`
- `/cdkeys`
- `/inventory`
- `/redeems`
- `/risk`
- `/admins`
- `/logs`

## 3. 页面模块设计

## 3.1 仪表盘

展示：

- 今日订单数
- 今日支付成功数
- 今日兑换成功数
- 待处理异常数
- 可用库存数
- 库存预警商品

## 3.2 商品管理

功能：

- 商品分页查询
- 新增商品
- 编辑商品
- 上下架
- 调整价格

列表字段：

- 商品 ID
- 名称
- 售价
- 状态
- 库存展示
- 创建时间

## 3.3 订单管理

功能：

- 订单搜索
- 订单详情
- 关闭未支付订单
- 查看订单关联卡密

筛选条件：

- 订单号
- 用户 ID
- 商品 ID
- 支付状态
- 创建时间范围

## 3.4 支付管理

功能：

- 支付单搜索
- 查看回调内容
- 对账状态查看
- 支付异常标记

## 3.5 CDKey 管理

功能：

- 卡密列表查询
- 批量生成卡密
- 批量导出非敏感信息
- 作废或锁定卡密

## 3.6 库存管理

功能：

- 批量导入库存
- 查看库存状态
- 禁用库存项
- 查看批次导入结果

重点要求：

- 敏感信息字段脱敏显示
- 导入失败要提供错误明细

## 3.7 兑换记录

功能：

- 查看兑换成功/失败记录
- 根据 CDKey、用户 ID、时间筛选
- 查看失败原因与风控命中结果

## 3.8 风控中心

功能：

- 黑名单管理
- 限流策略管理
- 命中记录查询

## 3.9 系统日志

功能：

- 管理员操作日志
- 登录日志
- 异常日志

## 4. 前端状态管理

建议 store：

- `useAdminAuthStore`
- `useDashboardStore`
- `useProductAdminStore`
- `useOrderAdminStore`
- `usePaymentAdminStore`
- `useCdkeyAdminStore`
- `useInventoryAdminStore`
- `useRiskAdminStore`

## 5. 表格与表单规范

- 列表页统一支持分页
- 搜索条件支持重置
- 敏感操作必须二次确认
- 导入导出必须有权限控制

## 6. 权限模型

推荐角色：

- `SUPER_ADMIN`
- `OPERATOR`
- `CUSTOMER_SERVICE`
- `FINANCE`
- `AUDITOR`

## 7. 管理后台 UI 设计约束

- 统一使用 Element Plus 组件
- 列表操作按钮数量不宜过多
- 表单尽量抽屉化或弹窗化
- 错误反馈明确到字段或批次
